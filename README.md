# Intel Site Localization - Project 3

This is the localized continuation of the Intel Sustainability Timeline project.

## What changed from Project 2

- Added English/Arabic language switching.
- Added right-to-left (RTL) layout support with Bootstrap RTL.
- Added JavaScript language detection for RTL languages.
- Added a new Bootstrap responsive three-column section with icons and styled Learn More buttons.
- Added a Bootstrap modal and accordion for extra interactivity.
- Added an accessible newsletter subscription form.
- Added a footer with simple navigation.
- Improved accessibility with semantic landmarks, alt text, visible labels, focus states, skip navigation, and reduced-motion support.

## Deployment

Upload the contents of this folder to a GitHub repository. Make sure `index.html` stays in the root of the repository, not inside another nested folder.

Recommended GitHub Pages URL format:

`https://YOUR-GITHUB-USERNAME.github.io/intel-site-localization/`

If you update the same repository from Project 2, your URL may instead use the original repository name.
